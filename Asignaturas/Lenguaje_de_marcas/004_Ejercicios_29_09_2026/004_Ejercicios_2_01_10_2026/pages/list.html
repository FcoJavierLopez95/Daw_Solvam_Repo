6. Listas

HTML proporciona distintos tipos de listas para agrupar elementos según la relación semántica que exista entre ellos.

6.1 Listas desordenadas

Elementos sin un orden estricto

Se utilizan cuando el orden de los elementos no altera el significado del contenido (ej. listas de la compra o menús de navegación).

  • <ul>: Para crear la lista desordenada (Unordered List).
  • <li>: Para cada elemento de la lista (List Item).

Demostración visual de listas desordenadas

  • <li>Primer elemento</li>
    • 
  
  • <li>Segundo elemento</li>
    • 


</ul>

6.2 Listas ordenadas

Secuencias e instrucciones

Se utilizan cuando la secuencia o la jerarquía de los elementos es imprescindible (ej. pasos de una receta o un ranking).

  • <ol>: Para crear la lista numerada secuencialmente (Ordered List).
  • <li>: Para representar cada paso de la secuencia.

Demostración visual de listas ordenadas

  1. <li>Primer paso</li>
    2. 
  
  2. <li>Segundo paso</li>
    3. 


</ol>

6.3 Listas de descripción

Diccionarios y glosarios

Se utilizan para asociar conceptos o nombres con sus respectivas explicaciones o valores.

  • <dl>: Contenedor padre de la lista (Description List).
  • <dt>: El concepto o término a definir (Description Term).
  • <dd>: La explicación o valor del término (Description Details).

Demostración visual de listas de descripción


<dl>


  
<dt>HTML</dt>

  
<dd>Lenguaje de marcado para la web</dd>

  
<dt>CSS</dt>

  
<dd>Lenguaje de hojas de estilo</dd>



</dl>
