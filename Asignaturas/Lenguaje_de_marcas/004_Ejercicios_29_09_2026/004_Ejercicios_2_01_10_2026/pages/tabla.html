7. Tablas

Nota: Las tablas se separan de las listas porque su complejidad técnica y semántica es mayor. Sirven exclusivamente para representar datos bidimensionales estructurados en filas y columnas.

7.1 Estructura básica

Filas y celdas simples

Las tablas más simples se construyen definiendo filas y, dentro de ellas, celdas de datos regulares.

  • <table>: Contenedor principal de la tabla.
  • <tr>: (Table Row) Define una fila horizontal.
  • <td>: (Table Data) Define una celda de datos estándar dentro de una fila.

Demostración visual de estructura básica


<table border="1">
  <tr>


  

    <td>Fila 1, Celda 1</td>
    <td>Fila 1, Celda 2</td>
  



  </tr>
</table>

7.2 Estructura semántica

Accesibilidad y estructuración avanzada

Para cumplir con los estándares profesionales, las tablas deben dividirse lógicamente y utilizar encabezados explícitos.

  • <caption>: Título o resumen de la tabla. Mejora enormemente la accesibilidad.
  • <thead>, <tbody>, <tfoot>: Cabecera, cuerpo principal y pie de la tabla.
  • <th>: (Table Header) Celda de cabecera. Utiliza el atributo scope="col" (columna) o scope="row" (fila) para indicar a qué datos aplica.

Demostración visual semántica

<table border="1">
  <caption>Alumnos de DAW</caption>
  <thead>
    <tr>
      <th scope="col">Nombre</th>
      <th scope="col">Módulo</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Javier</td>
      <td>Entornos de Desarrollo</td>
    </tr>
  </tbody>
</table>

7.4 Atajos de creación ( VS Code)

Generación rápida de código

Visual Studio Code permite usar abreviaturas de Emmet para crear estructuras escribiendo una sola línea.

  • >: Anida un elemento dentro de otro (hijo).
  • *: Multiplica el elemento por el número indicado.

Ejemplo práctico: Tabla de 3x3

Escribe esta línea y pulsa Tab o Enter:

table>tr*3>td*3

Resultado autogenerado:

  <tr>
    <td></td>

  </tr>

  </tr>
</table>
