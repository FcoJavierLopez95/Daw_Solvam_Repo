4. Contenedores Genéricos (El puente hacia CSS)

A diferencia de etiquetas como <header> o <p>, los contenedores genéricos no tienen ningún valor semántico. No le dicen nada al navegador ni a los motores de búsqueda sobre su contenido. Son "cajas vacías" cuya única finalidad es agrupar elementos para poder aplicarles estilos con CSS o manipularlos con JavaScript.

4.1 El bloque: <div>

El contenedor de bloque genérico

La etiqueta <div> (del inglés division) es el elemento contenedor más utilizado en la construcción de layouts (diseños) web.

  • Comportamiento por defecto: Es un elemento de bloque (block-level). Esto significa que siempre comienza en una línea nueva y ocupa todo el ancho disponible de su contenedor padre, empujando los siguientes elementos hacia abajo.
  • Caso de uso ideal: Agrupar un conjunto de elementos lógicos para aplicarles un sistema de cuadrícula (CSS Grid), flexbox, o para crear tarjetas visuales (cards).
  • Falta de semántica: Para un lector de pantalla o para Google, un <div> es invisible en cuanto a significado. Solo ven su contenido interno.

4.2 La línea: <span>

El contenedor en línea genérico

La etiqueta <span> es el hermano menor del <div>. Sirve exactamente para lo mismo (agrupar sin aportar significado), pero está diseñado para usarse dentro de fragmentos de texto u otros elementos en línea.

  • Comportamiento por defecto: Es un elemento en línea (inline). No genera saltos de línea y solo ocupa el ancho estrictamente necesario para envolver su contenido.
  • Caso de uso ideal: Aislar una palabra concreta dentro de un párrafo para cambiarle el color con CSS, o para inyectar un pequeño icono de una librería externa junto a un texto.
  • Restricción importante: Un <span> nunca debe contener elementos de bloque en su interior (como párrafos o encabezados). Solo debe contener texto u otros elementos inline.

4.3 Buenas prácticas y Clean Code

Cuándo usarlos y cuándo evitarlos

El abuso de contenedores genéricos es uno de los peores hábitos en el desarrollo web inicial, un antipatrón conocido en la industria como "divitis" (una enfermedad de divs).

  • La regla de oro semántica: Nunca uses un <div> si existe una etiqueta HTML5 que describa mejor esa sección. Si es un menú, usa <nav>. Si es el pie de página, usa <footer>.
  • El uso correcto (El puente): Usa los <div> cuando necesites una caja puramente visual. Por ejemplo, envolver una imagen y su texto para crear una "tarjeta" de producto, a la cual le añadirás una clase class="producto-card" para maquetarla en CSS.
  • Accesibilidad: Jamás uses un <div> o un <span> para simular un botón o un enlace dándoles estilo y un evento click con JavaScript. Esto destruye la navegación por teclado y bloquea a los lectores de pantalla. Usa siempre <button> o <a>.

Ejemplo de uso correcto de contenedores genéricos


<!-- El div agrupa contenido puramente por necesidades de diseño visual -->
<div class="tarjeta-usuario">
  <h3>Perfil de Usuario</h3>
  
  <!-- El span aísla una palabra específica para pintarla de rojo o verde en CSS -->
  <p>
    Estado de la cuenta: <span class="estado-activo">Verificada</span>
  </p>
  
  <button>Cerrar sesión</button>
</div>
