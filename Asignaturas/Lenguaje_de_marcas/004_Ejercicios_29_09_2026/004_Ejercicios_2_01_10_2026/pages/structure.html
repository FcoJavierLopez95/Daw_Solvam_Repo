2. Estructura del documento

Todo documento HTML profesional debe comenzar con una estructura base innegociable. Estas primeras líneas son las encargadas de decirle al navegador qué versión de HTML estás usando, cuál es la raíz de tu documento y en qué idioma está escrito el contenido.

2.1 <!DOCTYPE html>, la etiqueta <html> y el atributo lang

El preámbulo: <!DOCTYPE html>

Aunque va entre corchetes angulares, no es una etiqueta HTML, sino una declaración de tipo de documento.

  • Propósito: Le dice al navegador de forma explícita que el código que sigue es HTML5 moderno.
  • Clean Code: Evita que el navegador entre en el "Quirks Mode" (Modo de compatibilidad), el cual emula errores de navegadores antiguos y rompe los diseños actuales.
  • Regla de oro: Debe ser obligatoriamente la primera línea de tu documento, sin espacios ni saltos de línea previos.

El elemento raíz: <html>

Es la etiqueta contenedora principal y el punto de partida de todo tu código.

  • Contenedor global: Absolutamente todos los elementos de tu página (excepto el DOCTYPE) deben estar anidados dentro de las etiquetas de apertura <html> y cierre </html>.
  • Árbol del DOM: A nivel de arquitectura, esta etiqueta representa la raíz (root) absoluta del documento para el navegador.

El atributo lang (SEO y Accesibilidad)

Es el atributo obligatorio de la etiqueta raíz (ej. <html lang="es">) que indica el idioma principal del contenido.

  • Accesibilidad (a11y): Los lectores de pantalla (Screen Readers) usan este atributo para saber con qué acento pronunciar el texto. Si una web en español tiene lang="en", el lector la leerá con acento inglés, haciéndola incomprensible.
  • SEO: Ayuda a motores de búsqueda como Google a indexar tu página en los resultados correctos para los usuarios de cada región.
  • Traducción: Navegadores como Chrome lo utilizan para decidir si deben ofrecerle al usuario la traducción automática de la página.

Ejemplo del esqueleto base completo


<!DOCTYPE html>
<html lang="es">
  <head>
    <!-- Aquí irán los metadatos -->
  </head>
  <body>
    <!-- Aquí irá el contenido visible -->
  </body>
</html>

2.2 El <head>: Metadatos vitales, <title> y favicon

Contiene la configuración de tu página. Todo lo que anides aquí (salvo el título de la pestaña y el favicon) será invisible para el usuario, pero es vital para el navegador, el SEO y las redes sociales.

Codificación: <meta charset="UTF-8">

Es el metadato que asegura que el navegador interprete correctamente caracteres especiales, tildes, eñes y emojis.

  • Regla de Clean Code: Debe ser estrictamente el primer elemento dentro del <head>.
  • Seguridad: Colocarlo al principio evita vulnerabilidades de seguridad y fallos de renderizado al forzar al navegador a conocer la codificación antes de leer el resto.

Diseño Móvil (Responsive): viewport

Es la directiva obligatoria para que la web funcione de forma correcta y fluida en dispositivos móviles.

  • Código: <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • Funcionamiento: Le ordena al móvil que adapte la página al ancho de su pantalla (width=device-width) con un zoom normal (initial-scale=1.0), evitando que cargue la vista microscópica de escritorio.

El título: <title>

Es el texto descriptivo que aparece en la pestaña del navegador y como enlace principal en los resultados de búsqueda.

  • Importancia SEO: Es uno de los factores de posicionamiento orgánico más importantes en Google.
  • Buena práctica: Cada archivo HTML de tu proyecto debe tener un título único y representativo; nunca los dupliques entre distintas páginas.

El Favicon

Es el pequeño logotipo o icono que aparece junto al título de la página en las pestañas del navegador.

  • Código: <link rel="icon" href="icono.png" type="image/x-icon">
  • Usabilidad: Mejora drásticamente la experiencia del usuario, permitiendo localizar e identificar rápidamente tu web cuando se tienen múltiples pestañas abiertas.

2.3 El <body>: Donde vive el contenido visible

Si el <head> es el cerebro lleno de lógica invisible, el <body> es el cuerpo. Es el contenedor absoluto de todo lo que el usuario ve, lee e interactúa en la pantalla.

Reglas esenciales del contenedor

Su uso es restrictivo y debe obedecer los estándares estructurales del HTML5.

  • Unicidad: Al igual que el <head>, solo puede existir un único elemento <body> por documento HTML.
  • Contenido exclusivo: Las etiquetas visuales y de texto (como <main>, <header>, imágenes o formularios) deben vivir exclusivamente dentro de este bloque.
