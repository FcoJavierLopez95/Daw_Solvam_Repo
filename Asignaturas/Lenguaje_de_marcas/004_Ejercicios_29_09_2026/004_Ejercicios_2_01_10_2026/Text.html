5. Tipografía y Texto

HTML proporciona una rica variedad de etiquetas semánticas para dar significado y estructura al texto. Estas etiquetas no solo formatean el contenido visualmente, sino que indican a los navegadores, motores de búsqueda (SEO) y tecnologías asistivas (a11y) el propósito exacto de cada palabra.

5.1 Comentarios

Los comentarios son fragmentos de texto que el navegador ignora por completo y no muestra en la página web. Se utilizan para documentar el código, dejar notas o explicaciones para otros desarrolladores (o para ti mismo en el futuro), y para ocultar temporalmente partes del código mientras haces pruebas.

5.2 Jerarquía de encabezados (<h1> a <h6>)

Reglas de SEO y Accesibilidad

Los encabezados (headers) establecen la jerarquía del contenido, funcionando igual que el índice de un libro.

  • Propósito Semántico: Indican la estructura de la información a los motores de búsqueda y lectores de pantalla.
  • Niveles de Jerarquía: <h1> representa el título de mayor importancia, mientras que <h6> es el nivel más bajo.
  • No saltarse niveles (a11y): Por accesibilidad, nunca debes saltar de un <h2> a un <h4>. El orden debe ser estrictamente secuencial para que los usuarios ciegos puedan navegar el documento lógicamente.
  • Regla de oro de Clean Code: Jamás uses estas etiquetas simplemente para hacer el texto "más grande". El tamaño visual se gestiona siempre en CSS.

          
<h1>Este es un título de Nivel 1 (Principal)</h1>

          
<h2>Este es un título de Nivel 2 (Sección)</h2>

5.3 Párrafos (<p>), saltos (<br>) y separadores (<hr>)

El Párrafo: <p>

Es el elemento base para bloques de texto convencional. Al ser un elemento de bloque, genera automáticamente un margen superior e inferior.

  • Uso correcto: Debe contener únicamente texto, imágenes en línea u otros elementos semánticos de línea (como <strong> o <a>).

El Salto de Línea: <br>

Fuerza un salto de línea dentro de un mismo párrafo, como al escribir un poema o una dirección postal.

  • Cuándo usarlo: Solo cuando el salto de línea forma parte estructural del contenido (ej. las líneas de un poema no tendrían sentido todas seguidas).
  • Mala práctica (Clean Code): NUNCA uses múltiples etiquetas <br> seguidas para crear espacio en blanco o márgenes entre elementos. Ese es el trabajo de CSS (propiedades margin o padding).

El Separador Temático: <hr>

Representa un cambio de tema o una transición estructural en el documento (justo como las líneas horizontales que separan las distintas secciones de esta página).

  • Diferencia con <br>: Mientras que el <br> rompe una línea dentro de un mismo bloque lógico de texto, el <hr> se utiliza para separar bloques de contenido completamente distintos y no relacionados.
  • Semántica frente a diseño: Antiguamente se usaba solo para dibujar una línea visual. En HTML5 tiene peso semántico e indica a los lectores de pantalla y a los motores de búsqueda que el tema de lectura ha cambiado.

5.4 Enlaces (<a>) y atributos seguros

El ancla y el hipertexto

La etiqueta <a> (anchor) es la esencia de la Web, permitiendo conectar documentos entre sí.

  • El atributo href: Es obligatorio. Indica la URL de destino (puede ser una ruta absoluta hacia otra web o una ruta relativa dentro de tu propio proyecto).
  • Abrir en nueva pestaña: Se logra añadiendo target="_blank". Se usa habitualmente para enlaces que apuntan a páginas externas.
  • Seguridad vital (noopener): Si usas target="_blank", debes añadir SIEMPRE el atributo rel="noopener noreferrer". Esto evita vulnerabilidades de seguridad donde la página de destino podría tomar el control malicioso de tu página de origen mediante JavaScript.

5.6 Citas y referencias

Atribuyendo contenido a terceros

Cuando copies texto de otra fuente, es vital marcarlo correctamente por motivos de derechos de autor y SEO (evitar penalizaciones por contenido duplicado).

  • <blockquote>: Para citas largas o párrafos completos extraídos de otra fuente. Es un elemento de bloque.
  • <q>: Para citas cortas integradas directamente dentro de un párrafo normal (elemento en línea). El navegador suele añadir comillas automáticamente.
  • El atributo cite: Se usa en ambas etiquetas para indicar la URL de la fuente original.
  • <cite>: Sirve para referenciar el título de una obra (un libro, una película) o el autor del contenido.

5.7 Representación de código

Mostrando lenguajes de programación

Cuando necesites enseñar código fuente, debes utilizar etiquetas específicas que por defecto aplican fuentes monoespaciadas (tipo máquina de escribir).

  • <code>: Sirve para marcar fragmentos cortos de código informático integrados en una misma línea de texto.
  • <pre>: (Texto preformateado). Es un bloque que respeta exactamente los espacios en blanco, las tabulaciones y los saltos de línea tal y como los escribes en el editor. Suele usarse envolviendo a un <code>.
  • <kbd>: (Keyboard). Se utiliza para indicar una entrada o tecla que el usuario debe pulsar en su teclado.
